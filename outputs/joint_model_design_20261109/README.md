# Data profile for the joint hierarchical model design

Aggregate tables behind `docs/JOINT_MODEL_DESIGN.md`. Generated by `python3 code/tools/profile_joint_model_data.py` from the integrated review (`outputs/integrated_review_20261103/`). No unit- or record-level data are written here. Review-only; no model fitted.

- `unit_profile.csv` — survey units by program×taxon: areas, zeros, units per visit, multi-visit station-years, negative-binomial overdispersion.
- `variance_scales.csv` — station-history scales: between-station SD, within-station residual SD, role-year SD, detrended protected/reference log-ratio SD and lag-1, protected–reference year correlation. Uses log(value + half the smallest positive value); descriptive only.
- `effect_scales.csv`, `pooled_between_mpa_sd.csv`, `history_support.csv` — current per-history effects, pooled between-MPA SDs, before/after year support.
- `size_profile.csv`, `biomass_size_basis_units.csv` — size-pool sample sizes and spreads; how each biomass unit's size information is supported now.
- `prior_predictive_quantiles.csv`, `prior_predictive_check.json` — prior predictive simulation compared with observed density series.
