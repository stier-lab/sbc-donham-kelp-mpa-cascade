# Analysis Documentation

This directory contains public, analysis-facing documentation for the California
MPA kelp-forest pipeline.

Current entry points:

- `SATELLITE_SITING_RESULTS.md` - fixed-pair pre-designation tracking and placebo-date diagnostics; module 46, separate from primary effects. Design in `SATELLITE_SITING_PLAN.md`.

- `SHEEPHEAD_YOY_2026-10-19.md` - source-defined 10 cm sheephead size proxy, exact baseline reconstruction and fixed-route sensitivity; primary data remain unchanged.

- `BIOMASS_SINGLETON_REFIT_2026-10-18.md` - lobster reconciliation, scoped lobster/red-urchin singleton correction, changed individual contrasts and qualified pathway/annual-uncertainty results.

- `SOURCE_RECONCILIATION_2026-10-17.md` - verified Naples/report mapping, satellite missingness and geometry diagnostics, dated KFM/PISCO overlap candidates, and narrowed confirmation questions.

- `PRIMARY_UNCERTAINTY_2026-10-12.md` - exact 145-history calendar-HAC checks; nonsingular retained-diver Figure 4 fit; same-row AR1 limits and reproduction commands.

- `NAPLES_BIOMASS_INCLUSION_2026-10-12.md` - approved one-history addition, exclusion sensitivity, refit and diagnostic limits; current 145-history primary cohort.

- `COAUTHOR_SENSITIVITY_INTEGRATION_2026-10-12.md` - module 34, Gull KFM omissions, combined predators, stage-specific kelp limits and display-name crosswalk.
- `SHEEPHEAD_COEFFICIENT_SOURCE_CHECK_2026-10-12.md` - historical source trace of the unsupported PISCO lookup and verified Hamilton/Williams equations.
- `SHEEPHEAD_ALLOMETRY_REFIT_2026-10-12.md` - approved Hamilton correction, scoped input rebuild, numerical comparison and release checks.

- `RESULTS_SUMMARY.md` - machine-generated summary of the main analysis results.
- `RESILIENCE_SYNTHESIS.md` - plain-language guide to scripts `14`-`23`.
- `RESILIENCE_PIPELINE_INTEGRATION.md` - resilience claim-to-output audit trail.
- `CONCORDANCE_AUDIT.md` - manuscript/SI claim ledger tied to generated outputs.
- `REPO_READINESS_AUDIT.md` - current repo-readiness gate and residual risks.
- `FIGURE_VISUAL_AUDIT_2026-09-29.md` - no-title/no-subtitle figure render QA.
- `CRAIG_PRE_REVIEW_2026-09-29.md` - internal harsh pre-review notes.
- `ANALYSIS_REVISIONS.md` - historical comparison of the original analysis and
  the current reproducible pipeline.
- `pisco_reference_control_sensitivity.md` - PISCO reference-control sensitivity
  rationale and results from script `26`.
- `LTER_COUNT_REFIT_2026-10-10.md` - preserved COUNT-only refit audit, not the final
  combined-refit results.
- `STEP_DIRECTION_REFIT_2026-10-10.md` - combined refit after correcting six Step
  contrasts to after-minus-before.
- `KELP_CALIBRATION_QA_2026-10-12.md` - exact SBC 112.15 Table 5 verification;
  the current fixed slope does not reproduce its monthly calibration.
- `pbacips_shape_display.md` - all 37 retained pBACIPS fits, native model clocks,
  reconstruction checks and cache-only figure rendering.
- `pbacips_shape_legend.md` - nonlinear comparison and fitted-history atlas legends.

Current manuscript drafts, cover letters, Supporting Information construction,
and citation-source PDF copies live outside this public analysis repository in
the private manuscript workspace. They are intentionally absent here.
