# Archived documentation

These documents preserve superseded instructions and dated reviews. Use the current repository README for operating instructions. The manifest records original locations, archived locations, SHA256 checksums, reasons and recovery status.

The two root READMEs have been reconstructed from their recorded successful edits and pinned Git versions. Independent readouts from immediately before cleanup match the recovered text. They are saved as `repository_README_before_cleanup.md`; the committed base remains in `repository_README_at_HEAD.md`. The earlier Git-only recovery warning is superseded. The analysis repository's `recovery/README.md` documents the checks and their limits.

Other snapshots retain their original bytes. Relative links inside immutable snapshots use the original base path recorded in the manifest. Hash-bound audit reports and their CSVs remain at their original paths so verification and reproduction continue to work; they are historical evidence, not current policy. No source data or numerical results were deleted.
