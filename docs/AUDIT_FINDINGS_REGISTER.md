# Analysis audit findings and decisions

Updated November 1, 2026. Start here for the current interpretation of the recent analysis audits. Detailed evidence, code, numerical results and verification remain in the linked audit directories. This register summarizes them; it does not replace their frozen records.

**Paper status:** the recent review analyses have not been promoted to the manuscript, supplement or canonical results. A completed audit is not an adopted analysis. Historical README summaries can describe the existing manuscript while newer review outputs test different methods or cohorts.

**Status terms:** verified = supported by inspected evidence; user decision = explicit instruction; proposed = not adopted; unresolved = evidence or design decision still needed; rejected interpretation = a computed result cannot support the claimed biological interpretation.

## Decisions that govern the ongoing reviews

- Preserve researcher-advised and ecological-scope exclusions; do not select sites using baseline-trend significance or effect direction. Keep Gull PISCO distinct from excluded Gull KFM, and Anacapa SMR distinct from excluded Anacapa SMCA. Preserve Scott Hamilton’s reference exclusions and Jenn’s revised Naples pairing. - Use actual calendar years and observed follow-up; separate before–after changes from post-protection trajectories. Do not pool these as interchangeable effects.
- Keep site inclusion, temporal coverage, model eligibility and measurement validity as separate decisions.
- No numerical baseline-stability tolerance or final recovery-coverage gate has been adopted. The 140-history early-start subset remains a proposal, not the current manuscript cohort.
- Show changes before updating the paper. Keep review outputs isolated; no automatic promotion, sending or publication.
