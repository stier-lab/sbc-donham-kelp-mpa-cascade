## Figure Concordance

The 2026-09-29 visual pass removed chart-level titles and subtitles from the
figure source. The audit found no active `ggtitle()`, `labs(title/subtitle=...)`,
or titled `plot_annotation()` calls in `code/R`. A PDF text check across the
five main figures found none of the removed title/subtitle phrases. Panel tags,
axis labels, legends, map labels, direct labels, and category headers remain
because they are data interpretation aids rather than caption substitutes.
